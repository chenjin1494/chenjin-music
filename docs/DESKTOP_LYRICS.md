# 桌面歌词与关闭窗口行为

## Electron 透明歌词窗口（0.1.0）

0.1.0 的桌面歌词恢复使用 Electron 透明窗口和原有 Vue 界面，Windows、Linux 和 macOS 使用同一套歌词页面。发行包不再附带或启动独立的 C# 歌词宿主。歌词解析、播放时钟、用户偏好和持久化继续由主程序管理，歌词窗口通过现有 IPC 接收状态并执行工具栏操作。

Windows 歌词窗口使用无标题栏、无系统边框、透明且无阴影的配置，同时设置 `resizable: false` 和 `thickFrame: false`，避免系统非客户区边框介入透明画布。解锁后的拖动和边缘缩放由 Vue 页面处理，通过 IPC 更新窗口位置和尺寸；锁定和解锁保持创建时的窗口边框配置，仅切换点击穿透，不重设窗口焦点模式。整库快照保存保留主进程的最新设置，避免延迟提交的旧快照将锁定状态或位置回滚。歌词 HTML 在组件加载前即设置透明背景，首帧就绪后才显示窗口；刷新设置仅在属性变化时更新窗口输入模式、任务栏与透明度。从不同缩放的显示器或离屏位置恢复时，同步复核实际边界并纠正 Windows DPI 切换造成的尺寸偏差。歌词文档根节点、文字和段落层保持透明，悬停不绘制白色内边框。这些配置针对白线及闪烁问题；不同 Windows 版本、显卡驱动和桌面合成环境仍需实机验证，不能保证所有环境都没有绘制问题。

保留翻译、罗马音、顺序交换、简繁转换、歌词偏移、逐字时间与下一句预览。字体提供中文回退，长句根据可用空间调整显示字号。播放时逐字填色随真实播放进度推进，暂停时保持当前行和填色位置。外观配置中的桌面歌词字号、字体、字重、颜色与透明度覆盖相应普通偏好；透明度由 Electron 窗口应用一次，文字层不重复叠加。

鼠标经过解锁歌词时显示原有工具栏：显示主窗口、上一首、播放／暂停、下一首、字号调整、锁定、置顶和关闭歌词。解锁时可拖动并从边缘调整大小。锁定后鼠标点击穿透，请从系统托盘“解锁桌面歌词”或“设置 → 歌词”解锁。托盘和设置还提供“重置歌词位置”，恢复到主屏幕可见位置和可用尺寸。关闭歌词只关闭歌词显示，主程序与播放继续。

## 歌词编码与显示

0.1.0 支持 UTF-8（含 BOM）、UTF-16 LE／BE（含 BOM 或有明确空字节特征）、GB18030，避免 Windows 编辑器常用 UTF-16 歌词被错误当成 GB18030 解码。主歌词、翻译、罗马音和逐字歌词使用相同解码规则，保留扩展汉字和 emoji。

本地歌词每次播放优先重新读取文件，已有错误缓存不会盖过新解码结果；手动编辑版本仍优先。该修复针对字节编码和渲染问题，不会凭猜测改写已经损坏的文字。没有原始文件时，不能恢复文件里已经丢失的字符。

横向窗口足够高时可预览下一句，设置中可关闭。暂停隐藏、全屏隐藏、悬停隐藏、屏幕边界约束、置顶与任务栏显示由主程序继续管理，窗口移动和缩放后的边界会保存到设置。

## 关闭主窗口

点击窗口关闭按钮或按系统关闭快捷键，默认弹出原生确认：

- **隐藏到托盘**：保持播放，必要时启用托盘，以便重新打开窗口。
- **退出程序**：停止播放并退出所有窗口，保存当前状态。
- **取消**：保持窗口和播放，不保存新选择。

勾选“下次不再询问”后，托盘／退出选择会保存并在下次关闭及重启后复用。未勾选仍继续询问。重复关闭不会生成多个对话框。

在 **设置 → 桌面与网络 → 关闭主窗口时** 可选择“每次询问”“隐藏到托盘”或“退出程序”。选择“每次询问”即可恢复关闭确认。已有明确的旧关闭到托盘偏好会保留；新的默认是每次询问。

托盘的“退出”和更新安装等明确退出操作直接退出，不重复询问。该确认只针对主窗口，关闭桌面歌词不会触发主窗口退出选择。

## 验证范围

编码回归使用真实 MP3 旁的 UTF-16／GB18030 歌词文件与旧错误缓存。桌面歌词、外观和设置集成验收均在隔离用户资料目录中启动实际 Electron 应用，检查 Vue 歌词 DOM、文字和逐字填色、透明背景、工具栏、字体与外观覆盖、可选频谱、暂停行为、置顶、锁定、位置重置和重启后的设置恢复。暂停填色检查连续采样 2.2 秒，避免仅凭暂停瞬间的单次读取判定稳定。

DOM 与 Electron 窗口属性检查不能替代实际桌面合成。Windows 系统测试使用专用背景窗口和 `CopyFromScreen`，检查歌词窗口内外顶部四行像素、锁定时实际歌词像素上的点击穿透、工具栏输入和真实鼠标拖动／缩放。锁定与解锁各采样 12 次、间隔 250ms，比较暂停歌词区域像素指纹，并启用持续置顶循环；另覆盖六轮锁定／解锁及置顶／任务栏切换、离屏恢复和本机 100%／125% 显示器的边界复核。所有测试使用隔离资料目录，测试后恢复鼠标位置与前台窗口。短时采样不能证明所有显卡、缩放组合或长期运行永远没有异常。

关闭验收触发真实原生窗口 close 事件，并使用隔离 SQLite 与真实音频；对话框返回选择由测试桩提供，检查取消、记住选择、托盘启用、恢复询问、语言、并发关闭及真正退出。未声称自动操作原生对话框按钮。
