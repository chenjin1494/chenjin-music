# 桌面歌词与关闭窗口行为

## 歌词编码与显示

0.5.0 修复 Windows 编辑器常用 UTF-16 歌词被当成 GB18030 解码的问题。支持 UTF-8（含 BOM）、UTF-16 LE／BE（含 BOM 或有明确空字节特征）、GB18030；主歌词、翻译、罗马音和逐字歌词使用相同解码规则，保留扩展汉字和 emoji。

本地歌词每次播放优先重新读取文件，已有错误缓存不会盖过新解码结果；手动编辑版本仍优先。该修复针对字节编码和渲染问题，不会凭猜测改写已经损坏的文字。没有原始文件时，不能恢复文件里已经丢失的字符。

桌面歌词附带中文字体回退，避免符号字体导致无法阅读。长句根据窗口大小调整显示字号，保留独立字号配置；逐字进度随实际播放速度推算，暂停时停止推进；首次在暂停状态打开也能取得播放快照。翻译、罗马音和简繁转换延续原有设置。横向窗口足够高时可预览下一句，设置中可关闭。

透明度只在原生窗口应用一次。鼠标经过解锁歌词可显示工具栏：显示主窗口、上一首、播放／暂停、下一首、字号调整、锁定、置顶和关闭歌词。拖动手柄或歌词区域可移动窗口，解锁时可调整大小。

锁定后鼠标穿透，请从系统托盘“解锁桌面歌词”或“设置 → 歌词”解锁；托盘和设置还提供“重置歌词位置”，恢复到当前主屏幕可见位置和可用尺寸。关闭歌词只关闭歌词显示，主程序与播放继续。

## 关闭主窗口

点击窗口关闭按钮或按系统关闭快捷键，默认弹出原生确认：

- **隐藏到托盘**：保持播放，必要时启用托盘，以便重新打开窗口。
- **退出程序**：停止播放并退出所有窗口，保存当前状态。
- **取消**：保持窗口和播放，不保存新选择。

勾选“下次不再询问”后，托盘／退出选择会保存并在下次关闭及重启后复用。未勾选仍继续询问。重复关闭不会生成多个对话框。

在 **设置 → 桌面与网络 → 关闭主窗口时** 可选择“每次询问”“隐藏到托盘”或“退出程序”。选择“每次询问”即可恢复关闭确认。已有明确的旧关闭到托盘偏好会保留；新的默认是每次询问。

托盘的“退出”和更新安装等明确退出操作直接退出，不重复询问。该确认只针对主窗口，关闭桌面歌词不会触发主窗口退出选择。

## 验证范围

编码回归使用真实 MP3 旁的 UTF-16／GB18030 歌词文件与旧错误缓存。实际 Electron 验收检查歌词文字、逐字高亮、预览、字号、透明度、置顶、锁定、暂停隐藏、恢复位置、翻译及重启持久化。

关闭验收触发真实原生窗口 close 事件，并使用隔离 SQLite 与真实音频；对话框返回选择由测试桩提供，检查取消、记住选择、托盘启用、恢复询问、语言、并发关闭及真正退出。未声称自动操作原生对话框按钮。
