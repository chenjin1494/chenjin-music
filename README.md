# 琛瑾音乐

**为每一次聆听而设计。**

基于 Electron、Vue 和 TypeScript 独立实现的音乐桌面客户端，采用 Material You / Material 3 设计，支持本地音乐、在线音乐、桌面歌词与下载。Windows 10/11 x64 为优先支持平台；无需云端账号、云端存储或自建云服务。

**当前版本：0.1.0。** 功能更新与修复不自动递增版本号，只有用户明确要求才修改，见 [协作约定](AGENTS.md)。

[功能概览](#功能概览) · [获取与安装](#获取与安装) · [从源码开发](#从源码开发) · [文档与验证](#文档与验证)

## 功能概览

| 功能 | 支持内容 |
| --- | --- |
| 音乐库与播放 | 本地音频导入、在线搜索、歌单、收藏、播放队列、稍后播放与不喜欢规则 |
| 歌词 | 逐字歌词、翻译、罗马音、歌词编辑；桌面歌词支持下一句预览、长句适配、锁定、置顶与位置恢复 |
| 下载与离线播放 | 并发下载、暂停与断点恢复、MP3／FLAC 标签写入、歌词保存及已下载歌曲离线播放 |
| 外观 | Material 3 动态配色与深浅主题；全局及 40 类组件独立配置，支持预设、JSON 导入／导出 |
| 音效与系统控制 | 十段 EQ、混响、自定义 IR、声场、独立移调、输出设备与快捷键；Windows 系统媒体面板和媒体键 |
| 数据与互通 | 本地备份、LX 历史备份／数据目录导入；可选本地／局域网同步与 OpenAPI |

在线搜索用于获取歌曲资料，在线播放和下载由启用的音源脚本提供实际音频地址。项目不内置播放音源；请导入你选择并信任的 LX API 2.0 兼容脚本。平台接口的可用性取决于网络和外部服务。

## 获取与安装

Git 仓库只保存源码、配置、资源和测试输入，安装包通过 [GitHub Actions](https://github.com/chenjin1494/chenjin-music/actions/workflows/build.yml) 手动构建。

1. 有仓库写权限的维护者可点击 **Run workflow**，选择 `main` 和目标平台；其他使用者可先 Fork 仓库，再在自己的仓库运行工作流。
2. 构建成功后，从该次运行的 **Artifacts** 下载对应平台 ZIP；产物保留 30 天。
3. 解压 ZIP，使用其中的安装程序或便携程序，并按附带的 SHA-256 校验文件核对文件。

也可以下载已有成功工作流的产物。工作流不会自动创建 GitHub Release，详见 [一键构建说明](docs/GITHUB_BUILD.md)。

| 平台 | 构建产物 | 验证范围 |
| --- | --- | --- |
| Windows x64 | 安装版 EXE、便携版 EXE | 当前 0.1.0 已完成本机打包与主要功能实测 |
| Linux x64 | AppImage、deb | 历史 Ubuntu 版本有实测记录；当前源码可通过 Actions 构建 |
| macOS x64 | DMG | 已提供构建配置，尚未完成 macOS 实机运行验证 |

Windows 安装版提供安装目录选择，默认仅为当前用户安装到 `%LOCALAPPDATA%\Programs\chenjin-music`。便携版请放在可写目录中，音乐资料保存在 EXE 旁的 `data` 文件夹。当前 Windows 包未提供发行者代码签名。

## 开始使用

1. **本地音乐**：在首页导入 MP3、FLAC、WAV 等音频，加入歌单后即可播放。
2. **在线音乐**：在“音源管理”导入并启用可信脚本，然后搜索歌曲或浏览在线歌单。
3. **下载**：在设置中启用下载并选择保存目录，再为歌曲添加下载任务。
4. **外观与歌词**：在“设置 → 外观与体验”调整配色和组件样式；桌面歌词可独立调整字号、颜色、透明度与显示方式。
5. **备份**：定期导出音乐库；原 LX 用户可以导入 `.lxmc` 备份或旧数据目录。

关闭主窗口默认询问 **“隐藏到托盘／退出程序／取消”**，可勾选 **“下次不再询问”** 记住选择。恢复询问：**设置 → 桌面与网络 → 关闭主窗口时 → 每次询问**。

### 外观自定义

组件外观工作室支持全局和 40 类组件的颜色、圆角、间距、字体、透明度、阴影、尺寸与图标描边。侧栏、播放器和虚拟列表尺寸会同步调整布局，修改行高时保留浏览位置。

- [默认配置](appearance.default.json)：以主题默认值为基础。
- [完整组件示例](appearance.example.json)：可直接导入或编辑。
- [外观配置说明](docs/APPEARANCE.md)：配置格式、取值范围与覆盖优先级。

外观配置只包含样式，不包含歌曲、音乐库或音源脚本。

### 数据、备份与更新

音乐库通过独立 worker 使用 SQLite，保存歌单、设置、音源脚本、下载任务等资料。Windows 安装版默认资料目录为 `%APPDATA%\chenjin-music`；便携版使用程序旁的 `data`。迁移便携版时，应一并保留该目录。

支持自有 gzip／JSON 备份、LX `.lxmc` 历史备份和旧数据目录导入。导入旧 SQLite 目录前，请关闭原应用以完成 WAL 写入。覆盖恢复会先备份现有音乐库；设置或单歌单恢复保留其他资料。

应用内提供手动检查、下载和安装更新，**默认没有配置更新源**，不会后台自动检查或静默更新。更新清单需要提供安装包大小与 SHA-512；未配置更新源时，可手动运行新版安装包。详见 [更新说明](docs/UPDATE_COMPATIBILITY.md)。

### 可选接口

本地／局域网同步和 OpenAPI 均默认关闭，可在设置中启用：

- 独立分享链接使用 `chenjinmusic://`；旧 `lxmusic://` 关联仅在用户启用后生效。
- OpenAPI 默认端口 **23330**，支持状态、歌词、播放控制和 SSE；`/volume?volume=75` 使用 0–100，`/seek?offset=15` 为绝对秒数。
- 同步默认端口 **23332**，支持 LX v4 兼容客户端／服务端、设备管理、歌单及不喜欢规则同步和冲突处理。

## 从源码开发

需要 **Node.js 22 或更新版本**及 **pnpm**。当前 Actions 固定使用 Node.js 22.22.1、pnpm 11.7.0。

```sh
git clone https://github.com/chenjin1494/chenjin-music.git
cd chenjin-music
pnpm install --frozen-lockfile
pnpm dev
```

检查与生产构建：

```sh
pnpm typecheck
pnpm test
pnpm build
```

在对应操作系统上打包，以下命令会先执行生产构建，产物输出到 `release/`：

```sh
pnpm pack:win
pnpm pack:linux
pnpm pack:mac
```

调试时可用 `CHENJIN_TEST_USER_DATA` 指定隔离资料目录，仅开发模式生效。`PORTABLE_EXECUTABLE_DIR` 用于便携版存储。构建输出、依赖、缓存和运行资料均不提交到 Git。

## 文档与验证

当前 Windows 基线为 **31 个测试文件、287 项通过**。真实打包客户端另完成桌面歌词 15 项、关闭选择 9 项、Material 界面 11 项、Windows 系统媒体会话 8 项和启动生命周期 5 项验收；也验证了实际音频播放、断点下载、标签写入、SQLite 重启与立即退出保存。关闭对话框的选项由测试桩提供，窗口隐藏、播放、保存和进程退出真实执行。

启动测试以原生窗口显示、音乐库恢复和首屏可操作为终点：本机 5 次重复启动中位数从 **1040 ms 降至 619 ms**，约缩短 **40%**，首屏 JavaScript 减少约 **31%**。这是重复启动结果；新解包程序首轮仍观察到 8203 ms，不能据此推断其他设备或严格冷启动耗时。完整方法及原始记录说明见 [启动速度](docs/STARTUP.md)。

macOS 原生运行、物理多音频设备插拔、私人分享账号、生产远端更新与真实安装升级不在当前实机验证范围内。历史平台和性能结果按对应报告中的版本、环境及夹具理解。
